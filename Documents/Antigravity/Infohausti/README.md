# Infohausti RP

Portal de informações sobre Ribeirão Preto - turismo, transporte, serviços e dados.

## Estrutura do Projeto

- `content/` - Conteúdo das páginas e dados-fonte
- `templates/` - Templates HTML para gerar páginas
- `partials/` - Componentes HTML reutilizáveis
- `assets/` - Recursos estáticos (CSS, JS, imagens)
- `scripts/` - Scripts de build e auditoria
- `reports/` - Relatórios de auditoria e logs
